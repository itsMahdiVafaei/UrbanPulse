# سامانه شهروند هوشمند (UrbanPulse) — نسخه یکپارچه و تست‌شده

این بسته شامل **فرانت‌اند React/Vite** و **بک‌اند Django REST Framework** است که به‌صورت کامل
به یکدیگر متصل شده‌اند. تمام سناریوهای زیر به‌صورت خودکار (Playwright) تست و تأیید شده‌اند:

- ثبت‌نام و ورود شهروند
- ثبت درخواست همراه با عکس و موقعیت روی نقشه
- ورود اپراتور و ارجاع درخواست به اکیپ پیمانکار
- ورود پیمانکار و اعلام پایان مأموریت
- مشاهدهٔ وضعیت به‌روزشده توسط شهروند
- مدیریت شهروندان (فعال/مسدود) و پیمانکاران (افزودن اکیپ جدید) توسط اپراتور

## ساختار پروژه
```
UrbanPulse_full/
├── backend/     # Django REST API
├── frontend/    # React + Vite + Tailwind
├── start-backend.bat
└── start-frontend.bat
```

## پیش‌نیازها
- Python 3.10 یا بالاتر
- Node.js 18 یا بالاتر
- ترمینال **CMD** ویندوز (نه PowerShell)

## مرحله ۱: اجرای بک‌اند (پنجرهٔ CMD اول)

```bat
cd backend
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

باید این خط را ببینید:
```
Starting development server at http://127.0.0.1:8000/
```
این پنجره را باز نگه دارید.

## مرحله ۲: اجرای فرانت‌اند (پنجرهٔ CMD دوم)

```bat
cd frontend
npm install
npm run dev
```

آدرس نمایش‌داده‌شده (معمولاً `http://localhost:5173`) را در مرورگر باز کنید.

اگر روی ویندوز خطای مربوط به دسترسی npm گرفتید، `npm.cmd` را به‌جای `npm` بنویسید،
و اگر پوشهٔ `node_modules` قدیمی باقی مانده، آن را حذف و دوباره `npm install` را اجرا کنید.

## حساب‌های آماده برای تست

| نقش | شناسه ورود | رمز عبور |
|---|---|---|
| اپراتور شهرداری | `admin` | `admin123` |
| پیمانکار نمونه (اکیپ آسفالت) | `09121112233` | `123456` |
| شهروند | با «ثبت‌نام» یک حساب جدید بسازید | دلخواه |

این حساب‌ها به‌صورت خودکار توسط مایگریشن `core/migrations/0002_seed_data.py` هنگام اجرای
`python manage.py migrate` ساخته می‌شوند.

## سناریوی تست پیشنهادی (گام‌به‌گام)

1. در صفحهٔ اصلی روی «حساب کاربری ندارید؟ ثبت‌نام کنید» بزنید و یک شهروند جدید بسازید
   (نام، ایمیل، شماره همراه ۱۱ رقمی، رمز عبور، کد امنیتی). پس از تأیید، وارد داشبورد شهروندی می‌شوید.
2. روی «ثبت درخواست جدید» بزنید، فرم را کامل کنید (توضیحات حداقل ۷۰ کاراکتر، حداقل ۲ عکس JPG)،
   موقعیت را روی نقشه انتخاب و ثبت کنید. کد رهگیری نمایش داده می‌شود.
3. از داشبورد شهروندی خارج شوید (خروج از پنل عملیاتی) و با «پنل سازمان و پیمانکاران» وارد پنل اپراتور
   با `admin` / `admin123` شوید.
4. در تب «درخواست‌های کاربران»، درخواست تازه‌ثبت‌شده را ببینید، جزئیات/نقشه/عکس‌ها را بررسی کنید،
   سپس روی «ارجاع به اکیپ» بزنید و اکیپ نمونه را انتخاب کنید.
5. خارج شوید و با شمارهٔ `09121112233` و رمز `123456` به‌عنوان پیمانکار وارد شوید؛ مأموریت را
   مشاهده و روی «ثبت پایان مأموریت» بزنید.
6. دوباره با حساب شهروندی خود وارد شوید و ببینید وضعیت درخواست به «انجام شده» تغییر کرده است.
7. در پنل اپراتور، تب «مدیریت شهروندان» و «مدیریت پیمانکاران» را نیز برای فعال/مسدودسازی و
   افزودن اکیپ جدید امتحان کنید (برای پیمانکار جدید، اگر رمز عبور خالی بگذارید، رمز پیش‌فرض
   همان شماره همراه او خواهد بود).

## نکات فنی مهم

- بک‌اند روی SQLite اجرا می‌شود (فایل `backend/db.sqlite3`، به‌صورت خودکار ساخته می‌شود).
- عکس‌های آپلودی در `backend/media/requests/` ذخیره می‌شوند.
- برای اتصال به آدرس دیگر بک‌اند، فایل `frontend/.env.example` را به `.env` کپی و مقدار
  `VITE_API_URL` را ویرایش کنید.
- پنل مدیریت Django: `http://127.0.0.1:8000/admin/` (با کاربر `admin`).
- برای استقرار روی هاست واقعی، `DEBUG=False` و `SECRET_KEY` را در `backend/urbanpulse/settings.py`
  از متغیر محیطی بخوانید و `ALLOWED_HOSTS` را محدود کنید.
